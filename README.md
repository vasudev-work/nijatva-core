# nijatva-core — Nijatva

**Shared library**

Compose design system (colour, type, components) and the common utilities every Nijatva app needs: Storage Access Framework helpers, a text-to-speech wrapper, encrypted preferences, backup and restore, and a no-GMS base Application class.

## Why this exists first

Everything else depends on this. Build it before the apps so eight apps do not grow eight copies of the same helper.

Part of the [Nijatva](https://vasudev-work.github.io) suite by **DEVIRA**.

## Status

Repository created. Implementation follows the app build order in the suite tracker.
